在手机本地，把多个网页的指定数据集中在一屏。

WebMonitor 是一个在 iOS 设备本地运行的网页局部内容看板工具。 无需服务器代挂，不依赖云端爬虫，纯本地规则回放登录与取数，网页凭据安全存储于系统钥匙串。

操作系统 iOS 17.0+
架构模式 纯本地规则引擎 (Local Rules)
凭据存储 iOS Keychain (系统钥匙串)
第三方追踪 零采集 (NSPrivacyTracking = false)
01

解决什么问题

平时为了查看不同网站的话费余额、宽带套餐余量、云主机账单、第三方 API 配额或监控指标，我们常常需要反复打开手机浏览器、切换多个标签页、逐一输入密码并翻找对应页面。

传统方案要么依赖复杂的第三方云端爬虫（存在泄露 Cookie 和账号密码的风险），要么只能依赖网站主动提供接口或 App。 WebMonitor 提供了一种轻量且属于你自己的解决方式：在卡片内嵌网页中直接框选你需要关注的那一小块区域或数值，让多个站点的目标数据在同一张看板上集中刷新。

“客观、冷静、真实。我们不使用夸张的宣传词汇，不架设代挂机服务器，如实说明软件在设备本地的工作方式、适用范围与明确的能力边界。”
对比维度 传统云端爬虫 / 聚合服务 WebMonitor (本地看板)
运行环境 远程第三方服务器 你手中的 iPhone 本地 (WKWebView)
账号与 Cookie 必须上传给托管方托管 存储于本机 Keychain，绝不离机
遭遇验证码 通常失效或尝试暴力破解 自动暂停，卡片内嵌手动过人机校验
账号依赖 需要注册服务账号、按月付费 无账号体系，打开即用，纯本地运行
02

核心工作机制

WebMonitor 内部封装了强鲁棒性的通用页面解析与本地回放流水线，涵盖从点选、录制到定时静默抓取的全链路。

01. 网页局部点选与双模式展示

Precision Clipping

在卡片内展开网页后，点击工具栏上的十字准星即可点选页面中的任意文本、数字或容器区块。 支持「网页样式」（保留原网页局部视觉排版与 CSS 样式）与「纯文字」（仅提取文字片段并可自定义排序拼接）两种展示形态。

Shadow DOM 穿透 动态哈希类名过滤 多级定位器

02. 按步骤回放自动登录与取数

Step Sequencer

针对需要登录或多步点击才能呈现数据的站点，你在卡片内手动操作的过程可被记录为步骤序列；亦可在卡片详情中直观编排动作：打开网址、聚焦输入框、填入已存账号密码、勾选协议、点击确认或延时等待。 每次刷新时按顺序在本地 WebView 中重放，直达目标页面。

本地规则引擎 iOS 密码自动填充兼容 弹窗主动穿透

03. 独立登录态与凭据管理

Session Isolation

默认情况下，同一网站的卡片共享登录会话。如需在同一个站点同时监控多个不同的账号（例如两个云服务账号或不同手机号），可为单个卡片开启「独立登录态」。每个卡片拥有互相隔离的 Cookie 与存储上下文。

WKWebsiteDataStore 隔离 Keychain 凭据加密

04. 异常自动暂停与手动接管

Graceful Takeover

当目标网站出现图形验证码、Cloudflare Turnstile 验证、短信验证码或重大会话过期时，程序会自动暂停自动步骤，并在看板与卡片底部发出明确状态提示。 只需点击展开卡片网页手动完成验证，完成后卡片将在同一会话上继续执行取数。

反死循环机制 原地接回原步骤
03

适用范围与明确边界

为了避免不切实际的预期，我们如实公开 WebMonitor 的能力边界与运行约束：

  • 适用
    结构相对稳定的管理后台与状态页：如云服务账单、宽带/流量套餐、余额看板、后台统计指标及常规账号密码登录的站点。
  • 不具备
    不破解、不绕过验证码：应用不会暴力破解任何图形验证码或滑块校验。遇到此类安全挑战时，必须由你在卡片内手动点击完成。
  • 不具备
    无云端挂机服务器：所有刷新完全受 iOS 系统后台调度机制（Background Fetch）及当前网络连接限制，无法像 24 小时云主机那样实现秒级高频爬取。
  • 限制
    网站重构时的维护成本：若目标网站前端代码全面重构、原有 DOM 节点与文字彻底改变，需要在卡片详情中重新点选一次目标区域或调整步骤。
04

数据与隐私安全

WebMonitor 采用严格的本地优先（Local-First）安全原则：

• 无账号体系：打开即可使用，无注册、无登录、不收集你的个人资料。
• 零广告与第三方追踪：项目中未集成任何第三方统计、广告或行为追踪 SDK（声明 NSPrivacyTracking = false）。
• 凭据不离机：你的网站账号、密码、Cookie 与网页快照存储在设备本地的 iOS Keychain 和沙盒内，绝不上传到任何服务器。
• 全本地规则判定：页面判定、元素定位自愈与步骤调度全部由设备本地代码驱动，运行时不调用任何在线 AI 模型接口。
